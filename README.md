# Mercury in Skin Lightening Products — Public Database

A searchable, filterable public database of **2,105 skin lightening product samples** tested for mercury contamination, collected from 31 countries between 2009 and 2026.

## Key Findings

- **65.8%** of samples had mercury detected
- **49.1%** exceeded the 1 ppm regulatory limit
- **38.2%** were critical (≥ 1,000 ppm)
- Highest recorded: **210,000 ppm**
- Samples from 31 collection countries, 45 manufacturing countries

## Features

- Full-text search across brand, product, country, manufacturer
- Filter by source, mercury level, category, collection country, manufacturing country, year
- Sortable columns
- Analytics tab with bar charts
- Copy filtered results as CSV

## Technical Notes

This is a single self-contained HTML file with the full dataset embedded as JSON.  
No backend required. No tracking. No cookies.
